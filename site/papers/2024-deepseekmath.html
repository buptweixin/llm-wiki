五分钟重建

PPO 通常用 Critic 估计价值基线。大语言模型再配一套价值网络，会增加显存和训练成本。GRPO 改用同一道题的一组回答作为比较基线。

  1. 同题多次作答

    从旧策略采样一组回答，给每条回答打奖励分。

  2. 组内比较

    用奖励减去组均值，再按组标准差归一化，得到相对优势。GRPO 因此省去独立 Critic。

  3. 更新生成概率

    优势进入裁剪策略目标。参考模型的 KL 正则单独保留。

具体例子（教学假设）：同题四个回答的奖励是 [1,1,0,0]。均值为 0.5，标准差为 0.5。忽略稳定除数后，优势是 [+1,+1,-1,-1]。这里比较的是奖励差，不只是名次。

边界：省掉 Critic 不等于总显存必定减半。论文中 Pass@K 的观察也只支持其特定实验下的概率重分配解释，不能证明所有 RL 都无法扩展解题能力。

换个条件看机制

四条回答全得 1 分时，组相对优势是什么？是不是整个训练目标都没有梯度？

组相对优势全为零，策略 surrogate 部分没有这组回答的区分信号。KL 正则仍可能产生梯度，所以不能把两者混为一谈。

一页看懂

02

问题

论文研究数学预训练数据的选择与 RL 成本。PPO 的独立 Critic 增加显存和训练成本，稀疏末端奖励也使逐 token 价值预测更难；离线 RFT 缺乏在线探索。

方法

从 Common Crawl 迭代清洗 120B token 高质量数学语料（DeepSeekMath Corpus）；提出 GRPO，同一问题采样 G 个输出，用奖励减去组均值、再除以组标准差计算优势，砍掉 Critic 并将 KL 惩罚独立外置。

结果

7B 纯模型推理在竞赛级 MATH 达 51.7%（Top-1），Maj@64 达 60.9%，逼近 GPT-4；其代码基座实验支持数学迁移，采样实验支持本设定下主要提高已有正确解的概率；不能推出 GRPO 无法形成新能力。

机制深入：统一梯度系数与网页挖掘

证据与边界：Pass@K 揭示的真相

05

在竞赛级 MATH 测试中，7B 模型 Top-1 达到 51.7%，超越 Minerva 540B 与开源 70B 系列。但论文最深刻的洞察来自 SFT 与 RL 模型的采样消融实验：

边界与代价：

  • 零方差失效边界：若某道难题全错（全 0）或某道水题全对（全 1），组内标准差为 0，实现用稳定项避免除零后优势归零。该组的任务奖励 surrogate 没有梯度，KL 正则仍可能产生梯度；
  • 几何推理短板：纯文本预训练与网页数据在空间拓扑与图形几何上存在偏差，三角形/椭圆类题目显著弱于闭源通用大模型；
  • Few-shot 扩展受限：受限于 7B 体量，少样本提示对性能的拉升幅度弱于 GPT-4。

卡壳点与解答

06

Q1：为什么丢弃 Critic 改用组相对打分，不仅省显存，而且天然契合奖励模型的本质？

  • 评分与预测的分工：Reward Model 或程序规则给已生成的回答评分；Outcome 模式可以读完整答案后返回 0 或 1，Process 模式也可以逐推理步骤评分。Critic 则读取当前前缀，预测从这里继续生成的预期回报 $V(s_t)$。它预测价值，优势由奖励与价值基线进一步计算。区别不在于局部 token 与整条轨迹。
  • GRPO 替代的是基线估计：用同题回答的奖励均值作基线，再除以组标准差得到优势；它省掉独立 Critic，仍需要评分来源。程序能判分时，不需要神经奖励模型。
  • 显存与奖励尺度：省去 Critic 的参数、优化器与反向图成本，实际总显存收益取决于实现。组相对比较与同题候选偏好评分相契合，但奖励噪声仍会存在，不能说组内标准化消除一切校准误差。
  • 2026-10-25 补讲方法与表现：用「完整答案判卷」对照「半截推导预测得分」。第一次迁移回答仍把两者混在一起；第二次给组件识别题，正确区分评分与 Critic，并指出 GRPO 省掉后者。

Q2：在 Outcome 模式下全对或全错时，GRPO 与传统 PPO 的梯度行为有何不同？

  • GRPO：组内奖励全相同时，$r_i-\mathrm{mean}(\mathbf r)=0$。实现用微小稳定项避免除零后，优势全为零。该组的任务奖励 surrogate 没有梯度；原版 GRPO 的 KL 正则仍可能产生梯度。若关闭 KL 且没有其他损失，这组回答才没有该训练目标的更新信号。所有回答都得 0.6 分时同理，不限于全对或全错。
  • PPO：优势依赖奖励与 Critic 预测，不直接以本组奖励均值作比较。因此，组内回报相同不会强制其优势归零；也不能反过来说 PPO 总有非零梯度。
  • 终止步骤例子（教学简化）：忽略额外奖励、优势归一化和裁剪，终止后的价值为零，最后一步优势可写成 $A=R-V(s)$。两条回答都错，$R=0$；若 Critic 在最后动作前预测为 0.8 和 0.2，优势分别为 -0.8 和 -0.2。若 Critic 准确预测二者回报为零，优势也可以为零。实际 PPO 通常用 GAE 汇总多步 TD 误差；价值估计非零不保证每步 TD 误差、最终优势或参数梯度都非零，也不保证更新有益。
  • 2026-10-25 补讲方法与表现：用上述终止步骤例子解释「结果一样，仍可能低于预期」。用户随后在全得 0.6 分的迁移题中正确区分关闭 KL 与开启 KL 的行为。PPO 对比已讲解，尚未单独做无提示迁移检验。

Q3：如何看待「Pass@K 几乎没变，Maj@K 大幅跃升」这一现象？

  • 实验支持的解释：在论文 Figure 7 的模型、数据与有限采样 K 下，Maj@K 提高而 Pass@K 变化较小，支持收益主要来自提高已有正确回答的采样概率。它没有证明所有 RL 或 GRPO 本身无法形成新能力。
  • 有限采样的边界：训练前 K 次没答对，不等于正确答案概率严格为零。训练后答对，也不能单独证明这个答案以前已有非零概率。两种方向都不能只靠有限样本断言。
  • 反例（教学假设）：已知训练前正确概率很小但非零，测试恰好全部没采到；训练把它提高后频繁答对。这个场景反驳「以前没采到，所以以前完全不会」。它不证明每一道训练后答对的题都属于这个场景。
  • 2026-10-25 补讲方法与表现：首答认为「GRPO 绝对不行」；第一轮复验虽否定新能力断言，但理由转向单题不能代表整体。第二轮用单题低概率反例补讲后，回答抓住概率提高；仍须保留题设已知概率非零的限定。下次独立检验双向证据边界。

关联与来源

07
前置继承

PPO

GRPO 的直接理论基石：继承了重要性采样裁剪目标（Clipped Surrogate Objective）以防止策略单步漂移过激；GRPO 的改动在于彻底裁掉 Critic 价值模型与 GAE，改用组内相对归一化估计优势，并将 KL 惩罚独立外置。

下游应用

GeoAnchor

空间几何推理的强化对齐应用：GeoAnchor 在第四阶段强化学习中，直接采用了 GRPO + pattern reward 算法来端到端优化多模态模型对不同空间潜变量模式的选择策略。

自对齐对照

U-OPSD / S²VOPD

对齐信号来源的范式分叉：U-OPSD / S²VOPD 走的是模型自身自构造不对称信息差（自投票轨迹 / 图像退化降噪）进行逐 token 稠密教师分布蒸馏；GRPO 则是在策略采样组内计算标量相对奖励以策略梯度优化。
