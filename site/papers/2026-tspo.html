TSPO

Temporal Sampling Policy Optimization for Long-form Video Language Understanding

让长视频模型用答题结果教会轻量 temporal agent 选择 query 相关关键帧，再把选帧与生成答案放进同一个联合策略里用 GRPO 式强化学习优化。

一页看懂

02

问题

长视频只能稀疏抽帧，均匀采样可能漏掉 query 真正需要的短片段；但帧级标注缺失，离散选帧又不可直接反传。

方法

Temporal Agent 从 1 FPS 候选中概率化选帧；多组帧分别交给冻结 MLLM，用答案正确率和目标片段定位奖励做组相对策略优化。

结果

LongVideoBench +5.0%、MLVU +6.0%；但偏整体理解的 Video-MME 仅 +1.1%，说明方法更擅长 query-localization。

答案奖励只能说明一组帧够用，不能说明每一帧都必要；TSPO 用目标片段内选帧比例补上这层区分。

关键机制: 选帧策略如何学会

03

先把长视频按 1 FPS 变成候选帧，再用冻结 CLIP 和只有约 3.5M 可学习参数的 temporal agent 计算帧级与事件级相似度。

候选视频 + query
采样Gumbel Top-K
回答冻结 MLLM

训练时同一问题采样多组帧，组内比较奖励；推理时去掉 Gumbel 噪声做确定性选帧。

Gumbel 噪声负责探索不同的离散帧组合；GRPO 式目标负责根据相对奖励提高更好的选帧方案概率。冻结 MLLM 后，语言策略比率约掉，只更新 temporal sampling policy。

卡壳点

06

答对的一组帧是否意味着每一帧都真正有用？

不意味着。R_A 只说明整组帧足以让冻结 MLLM 答对；多组不同帧都可能包含足够证据。它是组级偏好信号，不能把功劳精确分给某一帧。

R_T 是 IoU 吗？Video-MME 上 TSPO 是否失效？

R_T 是选中目标片段的帧数占总选帧数的比例，更接近 precision，而不是完整 IoU。Video-MME 不是完全失效，只是整体理解占比高，所以 query-aware 局部定位优势较小。
