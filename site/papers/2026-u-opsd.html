U-OPSD

On-Policy Self-Distillation without Any Supervision

让模型给自己的答错题「开小灶」：它自己把一道无答案的题做 8 遍，多数票当标准答案，专门拿答错的那几版去对照「看过答案的自己」逐 token 纠正，全程不需要任何外部答案。首个完全无外部监督的 on-policy 自蒸馏。

一页看懂

02

问题

后训练谱系每往右一步去掉一类外部依赖：SFT 要 GT 解且教师强制导致训练-推理失配；GRPO 要 GT 答案做奖励且信号稀疏；OPD 要外部强教师；OPSD 参数自共享但教师仍多看 GT 解。GT 标注的成本与稀缺是规模化瓶颈。

方法

没有标准答案就把同一题独立做 8 遍，5 次算出 42 就当 42 是对的；拿「算出 42 的完整过程」当参考，逐 token 纠正「算错的那 3 次」。只纠答错的，不模仿答对的。

结果

Non-thinking 模式 4B/8B 比基座 +8.5/+10.7，无 GT 反而超过有 GT 的 OPSD（+3.2/+2.3）。代价：伪标签 13.3% 是错的，构成性能硬上界。

学习信号从「教师知道答案、学生不知道」的上下文差里长出来：学生若也看了伪解，教师 = 学生，KL 恒 0。

关键机制：采样 → 投票 → 门控 → 蒸馏

② Vote多数票赢的当伪答案；一致性 c(x)=同意票数/G（分母是 G，截断废票直接拉低分数）
③ Gatec(x)<τ=0.5 或全对 → 跳过不学：自发课程，只学「能形成共识但时不时跑偏」的能力边界题
④ Distill沿答错 rollout 逐 token 前向 KL
角色输入上下文看伪解 y+看错答前缀 y⁻<t
教师 π̄x + y+ + y⁻<t是是
学生 πθx + y⁻<t否是

两者共享 x + y⁻<t，教师比学生多出来的只有 y+（一条完整的同意 rollout，整条喂入不截断）。蒸馏沿 y⁻ 前缀逐 token 走完全长，纠正信号正好戳在「自信但错」的地方。

关键机制：三个消融出的硬取舍

04
取舍错误做法的后果为什么
教师必须看完整推理轨迹 label-only 掉 10.3~15.8%，甚至低于基座 光知道「答案是 42」无法引导中间步骤；y+ 必须是通向答案的整条路
必须 forward KL reverse KL 训练崩塌：长度 2.7k→99k、boxed 率 99%→33%、丧失终止 forward 是 mode-covering（老师会的都得会）；reverse 是 mode-seeking（只抱最高概率的峰，塌成复读机）；JSD 掉 13.8%
必须全词表分布蒸馏 sampled-token 掉 13.7%，且伪标签下差距比 GT 下更大（17.8% vs 2.0%） 噪声伪标签下逐 token 采样会放大噪声；好消息：top-100 截断反而最好，实用降本

卡壳点

06

为什么必须前向 KL，反向 KL 会崩？（08-24 复测暴露两处易记偏）

厨师比喻：前向 KL（老师‖学生）= 老师会的学生都得会，漏掉任何一道（哪怕低概率）就罚 → mode-covering，学生变成全面厨师。反向 KL（学生‖老师）= 学生敢做老师菜单外的菜就罚 → mode-seeking，学生死抱老师概率最高的招牌菜，其余全放弃。易记偏的两处：反向 KL 罚的是学生越菜单；实测失败模式是复读塌缩（长度爆炸、无限重复、丧失终止），不是幻觉。

13.3% 的错标签为什么没把模型带偏？

四重设计抬高净收益：门控先拦截瞎猜题（13.3% 是过门后的错误率）；自发课程聚焦能力边界（大多数时候对的题上 y+ 大概率对）；前向 KL + 全词表是稠密信号，一条 rollout 数百个纠正点，正梯度盖过少数错 y+ 的负梯度；教师不需要 y+ 完美，只需多数方向对，噪声 token 被平均。

y+ 是单个答案值还是多个 token？为什么 <t 只在 y⁻ 上？

ã(x) 是单值（如 boxed 42），用来投票和分组；y+ 是通向 ã(x) 的整条推理轨迹（几百上千 token），整条喂教师当背景知识，不截断。<t 在 y⁻ 上因为蒸馏沿答错那条逐 token 往前走：t 每加 1，在新位置算一次教师/学生的下一 token 分布 KL。label-only 消融掉 10.3~15.8% 的来由正是「只给答案值，教师不知道怎么走到这个答案」。

「共识被用作上下文」和 TTRL 类方法的本质区别？

TTRL/RENT/Intuitor 把多数投票当标量奖励（整条 rollout 一个数，稀疏）；U-OPSD 把共识当教师的特权上下文（y+ 拼进教师输入，每个 token 都有完整下一 token 分布，稠密）。同样 rollout 预算领先 7~11 个点的本质原因。
