SAO

Single-Rollout Asynchronous Optimization for Agentic Reinforcement Learning

SAO 用单 rollout 采样替代组采样消除长时程智能体异步训练的木桶等待瓶颈，配合冻结注意力的强 Critic、Skip-Observation GAE 与双侧硬门控裁剪（DIS），实现兼顾吞吐与千步稳训的智能体异步强化学习。

五分钟重建

GRPO 的组采样在长时程多轮智能体任务中面临严重的木桶等待瓶颈与版本交叉污染，而异步更新又常因策略滞后（Policy Lag）在百余步内迅速崩溃。SAO 废弃组采样，改用单轨迹即采即训，并引入双侧硬裁剪抵御离线偏差。

  1. 单轨迹异步回传

    每个 Prompt 仅生成一条轨迹（$G=1$），推理引擎逐 Token 记录行为概率 $\log \pi_{\text{rollout}}$，轨迹一旦完成立即回传训练队列，无需等待整组其他样本。

  2. 双频强价值估计

    Critic 预先在大规模回报数据上预训练冷启动，冻结自注意力层仅微调 MoE 参数，并以 $K=2$ 倍于策略的频率快更新；跨过环境反馈 Token 计算 Skip-Observation GAE。

  3. 双侧硬门控更新

    计算当前策略与生成时行为概率的比值 $r_t(\theta)$；若落在非对称宽信任区间 $[1-\epsilon_l, 1+\epsilon_h]$ 内则正常更新，一旦越界直接硬置零阻断梯度，避免陈旧轨迹毁坏模型。

具体例子（教学假设）：一条异步回传的轨迹中，某个 Token 经过若干步参数迭代后，概率比值漂移为 $r_t = 8.0$（$\epsilon_h = 5.0$）。在标准 PPO 下该 Token 被软截断为 $1+\epsilon$ 依然推动正向更新；而在 SAO 中由于 $8.0 > 1+5.0$，该 Token 门控直接置零，不产生任何梯度污染。

边界：依赖高并发推理引擎提供逐 Token 的生成对数概率；需要额外维护独立的 Critic 模型（显存开销与 PPO 相当，高于 GRPO）；若 Critic 缺乏充分的回报预训练冷启动，单 Rollout 的高方差会导致收敛困难。

换个条件看机制

如果去除 Skip-Observation 设计，把终端返回的 500 行编译器报错也纳入 GAE 链条计算，会发生什么？

Critic 会被迫尝试去预测外部随机环境的状态转移价值，导致优势估计被无关的环境噪声严重污染，破坏模型自身动作的信用分配。

一页看懂

02

痛点

GRPO 组采样在智能体多轮长轨迹中遭遇严重的木桶等待瓶颈；异步更新又因策略滞后在百余步崩溃；外部环境回包更会严重污染 GAE 优势计算。

方法

SAO 废除组采样改用单 Rollout（G=1）即采即训，以强 Critic 压制方差；配合 Skip-Observation GAE 跨过环境回包，并引入 DIS 双侧硬门控置零，宁可不学绝不学歪。

结果

实现长时程智能体异步 RL 超 1000 步极限稳训；在 AIME2025（97.3%）、SWE-Bench Verified（29.8%）等基准大幅超越 GRPO，并成功赋能开源 750B 大模型 GLM-5.2。

SAO 用单 rollout 采样替代组采样消除长时程智能体异步训练的木桶等待瓶颈，配合冻结注意力的强 Critic、Skip-Observation GAE 与双侧硬门控裁剪（DIS），实现兼顾吞吐与千步稳训的智能体异步强化学习。

关键机制：单 Rollout 与双侧硬门控 DIS

03

直接利用推理引擎记录的生成对数概率，省去旧策略前向推理并施行硬门控：

r_t(θ) = exp( log π_θ(a_t | s_t) - log π_rollout(a_t | s_t) )
f(x)   = x  (若 1 - ε_l < x < 1 + ε_h),  否则 0 (梯度直接置零)
对比维度GRPO 组采样标准 PPO / VAPOSAO（本篇）
采样结构 同题采一组（G≥8） 批次采样或异步队列 单轨迹即采即训（G=1）
基线模型 无需 Critic（组内均值） 全参数 Critic 冻结自注意力强 Critic + 快更新（K=2）
越界处理 组相对优势裁剪 软截断（仍提供同向梯度推进） 双侧硬门控置零（梯度完全阻断）
异步稳定性 约 160 步崩溃 约 90 步崩溃 极限稳训 1000 步以上

机制深入：环境反馈隔离与价值模型双频更新

04

Skip-Observation GAE 阻断外部噪声

智能体轨迹中终端回传的几百行报错并非模型生成。SAO 在时序差分中直接跨过观测区间，仅连接模型的前后动作边界，保证优势估计不受环境随机性干扰。

Frozen Attention 压死梯度范数

消融证实冻结 Critic 的自注意力层是稳训最关键的一环（去掉性能骤降 6.7 分）。既复用了语言先验，又将 Critic 梯度的狂暴方差锁死在平稳区间。

证据与边界：基准评测与千步稳训

05

边界与权衡：

  • 显存开销：恢复独立 Critic 带来双倍显存占用，与标准 PPO 相当，高于 GRPO。
  • 冷启动要求：依赖海量回报数据进行 Critic 预训练，若冷启动不足则单 Rollout 无法收敛。
  • 推理引擎侵入：必须要求分布式推理集群导出逐 Token 的真实采样对数概率。

卡壳点与解答

06

Q1：DIS 的双侧硬门控和 PPO 的 Clip 截断到底有什么本质区别？为什么异步下必须置零？

  • PPO 的饱和截断：当比值越界时，强行以边界值 $1+\epsilon$ 计算，梯度依然存在且持续推动更新。在同步同分布下这能提供稳定的保守更新；但在异步集群中，严重越界的比值代表数据产生自极为陈旧的模型快照，该动作在当前策略下已经被认定为不可信。若继续以 $1+\epsilon$ 强推，累积的 Off-policy 伪梯度会在百余步内直接撕裂分布。
  • DIS 的硬门控置零：DIS 采取硬门控置零（$f=0$），直接关闭该 Token 的梯度流，宁可不学、绝不学歪。

Q2：单 Rollout 的单题方差天然高于组采样，为什么长时程智能体整体训练效果反而大幅超越 GRPO？

  • 核心矛盾转换：长时程多轮智能体任务在固定算力预算下的核心矛盾是「木桶等待造成的算力空转」与「Prompt 覆盖多样性严重匮乏」。
  • 多样性带来质变：GRPO 同一题采 8 条，不仅导致快节点苦等慢节点，而且见到的题目种类只有 1/8。SAO 凭借预训练充分且冻结注意力的 Critic 吸收掉了单题方差，同时将 Prompt 探索空间拓宽了 8 倍，因而在复杂推理与工程编码等考验知识广度与深度探索的基准上达成全面领先。

Q3：智能体多轮轨迹中的环境观测（Terminal 输出）为什么不能顺次参与 GAE 时序差分？

  • 非策略生成内容：外部观测 Token（例如 500 行编译器报错或 Bash 执行结果）并非模型策略生成，其文本分布由外部编译器、解释器或沙盒物理环境决定。
  • 物理隔离噪声：若不跨过这些 Token，Critic 网络会强行去建模外部环境的状态转移概率，导致时序差分误差被外界随机性严重污染，无法为模型前后的真实动作进行正确的信用分配。

关联与来源

07
范式对比

DeepSeekMath

去 Critic 的组相对优势范式：GRPO 在短推理中极简高效，但在长时程异步环境中暴露出木桶同步屏障；SAO 重构了单 Rollout 与强 Critic 架构。

算法演进

PPO

从三模型软截断到单 Rollout 硬门控：SAO 继承了 Actor-Critic 与 GAE 体系，但废除旧模型推理，改用推理端 log-prob 与双侧硬置零门控 DIS。

异曲同工

GSPO

长轨迹稳定性的另一维度演进：GSPO 采用序列级几何平均似然比抵抗 MoE 路由跳变；SAO 则立足异步流水线，以单 Rollout 与 DIS 稳训千步。
