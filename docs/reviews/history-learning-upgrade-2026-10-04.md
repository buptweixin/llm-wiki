## 工程维护

- 新增 `scripts/sync-note-pages.mjs`，从 Markdown 生成完整笔记并保留历史问答 ID。使用写作环境的 marked，不增加线上运行时或构建服务；公式作为可读 TeX 保留，避免下标和括号被 Markdown 误解析。
- `build-wiki-index.mjs` 从真源读取一句话本质与学习入口，清除过时的速览检索片段，重建为 16 页 / 240 条全文与问答条目。搜索摘要剥离真实 HTML 标签，保留文字。
- C16 检查学习入口唯一且逐字投影、预测答案默认收起、待试用状态、搜索无标签泄漏、每篇单一最高强调、原图数量/唯一引用/替代文字/同源图注。
- 论文/专题源模板、速览/导读模板与 ingest 命令同步。共享 CSS 与全站 HTML 资源版本统一为 `20261004-3`。

重建顺序：修改 Markdown → 同步速览/导读 → 生成完整笔记 → 复核变化的关系依据 → 更新指纹 → 重建索引 → 检查 → 部署。生成器用法：

```sh
node scripts/sync-note-pages.mjs --modules /path/to/node_modules
node scripts/build-wiki-index.mjs
node scripts/check-site.mjs
```
