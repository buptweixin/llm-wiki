## 2. 必须修复的问题

### T1 · P2：完整笔记会清除来源中的主题和标签

位置：[wiki-slides.js](../../site/assets/wiki-slides.js) 第 163～179、815～824 行；[完整笔记模板](../../site/_note-template.html) 及九篇完整笔记的脚本加载。

**复现路径一（直接命中完整笔记）：**

1. 在首页搜索 `stop-gradient`，同时选择 `topic=distillation`、`tag=self-distillation`。
2. 点击 U-OPSD 的搜索片段，进入完整笔记 `#mechanism`。
3. 点击顶部“速览页”，再点“知识库”。

预期回到相同的关键词、主题和标签。实际只剩 `?q=stop-gradient`。

进入完整笔记时，URL 中的 `from` 本来完整包含三项；但页面生成的首页链接已经变成：

```text
../../index.html?q=stop-gradient
```

**复现路径二（从速览进入完整笔记）：**

首页 `q=流式 掩码&topic=video-understanding&tag=memory` → VST 速览 → 首屏“完整笔记” → 速览／知识库。同样只保留关键词。此路径在本地 HTTP 复现，第一条在 file:// 复现。

另以 09-14 到期状态验证 `q/ topic/ tag/ review=due` 四字段：完整笔记保留 q 与 review，丢弃 topic 与 tag。

**原因：** 完整笔记只加载 wiki-slides.js，没有加载 WIKI_TOPICS / WIKI_TAXONOMY 数据；fromQuery() 却依赖这两份数据校验来源。空词表使 resolveTag() 返回 null，空专题表使合法 topic 被重置为 all。浏览器没有报错，状态被静默截断。

**修复标准：**

- 完整笔记保留合法来源字段；可补充所需数据，或将来源解析与页面是否加载全站索引解耦。
- 模板与全部完整笔记保持一致。
- 对包含空格、字面 `+`、中文的 q，分别组合 topic、tag、review，验证直接返回、顶部切换、页脚切换与再返回，四字段和值都不改变。
- 同时复验 file:// 和 HTTP；不要只测 q 或只测速览页面。

### T2 · P2：全文命中只定位到章节开头，实际段落仍在几屏之外

位置：[索引生成器](../../scripts/build-wiki-index.mjs) 第 103～105 行；完整笔记中的段落锚点与定位。

**复现：**

1. 390×844 下，首页搜索 `Dataset-S2`。
2. 点击 GenLIP 的“全文 · 关键机制”结果。
3. 实际打开 `notes/papers/2026-genlip.html#mechanism`，显示 Prefix-LM 与 Gated Attention；包含 Dataset-S2 的“阶段二”段落在视口 y≈1508～1616px，仍需继续寻找。
4. 搜索 `59.01` 打开 U-OPSD `#evidence` 也一样：匹配段落位于视口 y≈1057～1192px，844px 屏幕中不可见。

这些结果的路径和内容都真实存在，因此不是上一轮的错误文件问题；但尚未实现第二轮第 4 节要求的“可见的正文落点”。桌面也能复现：GenLIP 的 Dataset-S2 段落在一次 863px 高视口中位于 y≈1028px。

**原因：** 每个二级章节全文聚合成一条索引，锚点只到 #mechanism / #evidence；片段截取知道命中发生在哪里，导航目标没有保留这个位置。完整笔记也没有进一步定位匹配段落。部分章节标题本身还贴在顶栏下方或被顶栏覆盖。

**修复标准：**

- 为具体段落／子节／问答提供稳定目标，或到达完整笔记后定位实际匹配内容；不能只检查章节 ID 存在。
- 命中的上下文和所属问题／子标题在可视区域内，预留顶栏偏移。优先使用能直接解释命中的最小合理段落。
- 复验 `Dataset-S2`、`59.01`，再从不同长章节的中部、尾部抽取新词；一次结果点击后无需继续滚动寻找匹配文字。
- 不要求全部正文逐字高亮；验收重点是准确抵达可读上下文。

### T4 · P2：比较中的同页“回依据”不关闭弹窗

位置：[wiki-slides.js](../../site/assets/wiki-slides.js) 的 makeCompareDialog()，尤其第 541～547 行的关闭处理与比较链接。

**复现：**

**修复标准：**

- 点击同文档依据时关闭比较，展开目标并定位；处理关闭时的焦点恢复，避免又回到触发按钮而离开依据。
- 对 U-OPSD、S²VOPD 各检查当前页依据、另一篇依据和完整笔记假说声明。
- 点击后无需额外关闭弹窗，目标内容可见并可操作；键盘激活和鼠标点击一致，Esc 原有退出行为保留。
